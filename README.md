# 🛒 E-Commerce Cart Page

Bu proje, HTML5, CSS3, JavaScript ve Fake Store API kullanılarak geliştirilmiş modern bir e-ticaret sepet sayfasıdır.  
Kullanıcıların ürünleri görüntüleyip sepete ekleyebileceği, adetlerini belirleyip toplam fiyatı görebileceği interaktif bir alışveriş deneyimi sunar.

## 🚀 Özellikler

- ✅ Ürün Listeleme (API ile)
- 🛒 Sepete Ürün Ekleme / Kaldırma
- ➕➖ Ürün Adetini Belirleme
- 💰 Toplam Fiyat Hesaplama
- 📱 Duyarlı (Responsive) Tasarım
- 🎨 Kullanıcı Dostu Arayüz

## 🛠️ Kullanılan Teknolojiler

- HTML5  
- CSS3  
- SCSS  
- JavaScript (Vanilla JS)  
- Fake Store API
